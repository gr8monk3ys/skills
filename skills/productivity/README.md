# productivity/ — promoted skills

Skills for managing conversations, handoffs, and decisions. This is a promoted bucket: everything here ships in `plugin.json`, the README/CLAUDE.md tables, and `lcc install`.

## User-invoked

- **[handoff](./handoff/SKILL.md)** — Compact the current conversation into a handoff document for another agent to pick up.
- **[wait-what](./wait-what/SKILL.md)** — Stop. That last message did not land — re-pitch it.
- **[to-questionnaire](./to-questionnaire/SKILL.md)** — Turn a decision you can't fully answer into a questionnaire for someone else to fill in.

### Shortcuts for prompts typed over and over

Mined from real session history: each replaces a prompt that was being retyped by hand.

- **[do-it-all](./do-it-all/SKILL.md)** — Approve everything just recommended and carry it all out, with agents where it helps.
- **[what-else](./what-else/SKILL.md)** — Benchmark against the best of its kind and rank the next moves.
- **[full-review](./full-review/SKILL.md)** — Code, security and architecture review, then fix everything in one PR.
- **[until-done](./until-done/SKILL.md)** — Self-paced loop to a written finish line, sending builds as they land.
- **[brutal](./brutal/SKILL.md)** — Brutally honest percent-done and slop check.
- **[pick-up](./pick-up/SKILL.md)** — Resume a paused or separate session from its real state.
- **[my-steps](./my-steps/SKILL.md)** — Do your part, hand me exact steps for mine.
- **[lscat-style](./lscat-style/SKILL.md)** — Match the lscaturchio.xyz design system.
